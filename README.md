
<p><strong>Версия:</strong> 1.0<br>
<strong>Платформа:</strong> Raspberry Pi + Zigbee2MQTT + MySQL + PHP<br>
<strong>Доступ:</strong> Веб-интерфейс, адаптив под мобильные устройства</p>

<hr>

<h2>📊 Главный дашборд</h2>
<p>Центральная страница мониторинга всей системы.</p>
<ul>
    <li>🕔 Текущее время на сервере</li>
    <li>✅ Последнее выполненное правило автоматизации (название, действие, время, статус подтверждения)</li>
    <li>⏱️ Следующее запланированное срабатывание</li>
    <li>🖥️ Статус железа Raspberry Pi:
        <ul>
            <li>Температура CPU (цветовая индикация: зелёный &lt;60°, жёлтый 60-70°, красный &gt;70°)</li>
            <li>Загрузка CPU</li>
            <li>Оперативная память (использовано / всего)</li>
            <li>Температура NVMe диска</li>
            <li>Скорость вентилятора</li>
            <li>Напряжение ядра</li>
            <li>IP-адреса, uptime, время последнего обновления</li>
        </ul>
    </li>
    <li>🔧 Статусы systemd сервисов:
        <ul>
            <li>iot-automation.service — движок автоматизаций</li>
            <li>mqtt-to-mysql.service — парсер MQTT в БД</li>
            <li>zigbee2mqtt.service — шлюз Zigbee устройств</li>
            <li>mosquitto.service — MQTT брокер</li>
        </ul>
    </li>
    <li>📊 Анализ логов (количество событий по ключевым словам за сегодня)</li>
    <li>⏰ Ближайшие автоматизации (до 6 штук)</li>
    <li>🌤️ Погода в Москве и Калуге (температура, ветер, влажность, давление)</li>
</ul>

<hr>

<h2>📈 Графики датчиков</h2>
<p>Визуализация показателей датчиков в реальном времени с историей.</p>
<ul>
    <li>📋 Группировка датчиков по зонам (Дом, Дача, Общие)</li>
    <li>📊 Карточки датчиков с:
        <ul>
            <li>Иконкой, названием и комнатой</li>
            <li>Текущим значением с цветовой индикацией (температура, влажность, батарея)</li>
            <li>Временем последнего обновления</li>
            <li>Датой первого появления в системе</li>
            <li>Графиком изменения за последние 30 точек (Chart.js)</li>
        </ul>
    </li>
    <li>🔄 Автообновление значений каждые 30 секунд и графиков каждую минуту</li>
    <li>📱 Адаптивная сетка (1 колонка на телефоне, до 5 на ПК)</li>
</ul>

<p><strong>Поддерживаемые типы датчиков:</strong> температура (°C), влажность (%), освещённость (лк), PM2.5, CO₂, напряжение (В), ток (А), мощность (Вт), энергия (кВт·ч), батарея (%), давление (гПа).</p>

<hr>

<h2>⚙️ Логика автоматизации</h2>
<p>Создание и управление правилами — сердце умного дома.</p>
<ul>
    <li>📝 CRUD операции с правилами (создание, чтение, редактирование, удаление)</li>
    <li>🎯 Типы активации:
        <ul>
            <li>По триггеру (при получении MQTT сообщения)</li>
            <li>Ежедневно в заданное время</li>
            <li>Еженедельно по выбранным дням</li>
        </ul>
    </li>
    <li>📊 Типы условий:
        <ul>
            <li>Простое (операторы: &gt;, &lt;, =, !=, &gt;=, &lt;=)</li>
            <li>Скриптовое (выражения с sensor.{topic}, data, &amp;&amp;, ||)</li>
        </ul>
    </li>
    <li>⏱️ Длительность условия (условие должно выполняться N секунд)</li>
    <li>📨 Действия:
        <ul>
            <li>MQTT команда (топик + payload)</li>
            <li>Email уведомление (с возможностью задержки)</li>
        </ul>
    </li>
    <li>✅ Подтверждение выполнения (топик подтверждения, таймаут, повторы)</li>
    <li>⏰ Ограничения по времени суток и зависимости от других устройств</li>
    <li>🔄 Повторение правила (persistent)</li>
    <li>🔘 Включение/выключение правил</li>
</ul>

<h2>🔧 Технические детали</h2>
<ul>
    <li><strong>Язык:</strong> PHP 8+</li>
    <li><strong>База данных:</strong> MySQL / MariaDB</li>
    <li><strong>MQTT брокер:</strong> Mosquitto</li>
    <li><strong>Zigbee шлюз:</strong> Zigbee2MQTT</li>
    <li><strong>Графики:</strong> Chart.js</li>
    <li><strong>Стили:</strong> Единый CSS с тёмной/светлой темой</li>
    <li><strong>Адаптив:</strong> Медиа-запросы для мобильных устройств</li>
    <li><strong>PWA:</strong> Установка на телефон как приложение</li>
    <li><strong>Автоматизация:</strong> systemd сервисы + cron</li>
    <li><strong>Клонирование:</strong> Ежемесячное зеркалирование на резервный сервер через WireGuard</li>
</ul>
