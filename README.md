# iot_system
Домашняя автоматизация на zigbee2mqtt, Mosquitto, MariaDB и самописной PHP-панели
Версия: 1.0
Платформа: Raspberry Pi + Zigbee2MQTT + MySQL + PHP
Доступ: Веб-интерфейс, адаптив под мобильные устройства

Поддерживаемые типы датчиков: температура (°C), влажность (%), освещённость (лк), PM2.5, CO₂, напряжение (В), ток (А), мощность (Вт), энергия (кВт·ч), батарея (%), давление (гПа).

📊 Баланс генерации и потребления
🏠 Комнаты: температура, влажность, тёплые полы, датчики движения
🧖‍♂️ Банный комплекс: парилка, купель, помывочная

🌬️ Вентиляция: рекуператор, грунтовый теплообменник, CO₂
🧊 Теплоаккумулятор 2000 л: температура, зарядка, ТЭНы
🔋 Zigbee батарейки: список устройств с уровнем заряда и предупреждениями
🐟 Аквариумы: 2 аквариума с датчиками (температура, pH, фильтры, корм)
🔧 Технические детали
Язык: PHP 8+
База данных: MySQL / MariaDB
MQTT брокер: Mosquitto
Zigbee шлюз: Zigbee2MQTT
Графики: Chart.js
Стили: Единый CSS с тёмной/светлой темой
Адаптив: Медиа-запросы для мобильных устройств
PWA: Установка на телефон как приложение
Автоматизация: systemd сервисы + cron
Клонирование: Ежемесячное зеркалирование на резервный сервер через WireGuard
